## The two mailer types in plain English

### Non-gated Mailers (Folder 1) — RECOMMENDED default

Customer clicks the green button → goes straight to Trustpilot's review form with their order metadata pre-filled.

- One click, no second decision.
- Every customer is invited to Trustpilot equally — no rating filter.
- Fully compliant with Trustpilot Business Guidelines, FTC CRFA (US), UK DMCC Act 2025.
- Best for: Brand Advocates, Loyalty VIPs, and any cohort you don't pre-judge.

### Gated Mailers (Folder 2) — USE WITH CAUTION

Customer sees 5 stars inside the email. Tapping a star records the rating, then:
- 4–5★ → redirected to Trustpilot (public review)
- 1–3★ → redirected to a private feedback form (CX only)

- Higher rate-of-tap because the action is in the inbox.
- Captures negative sentiment for CX before it goes public.
- **⚠️ This is the pattern Trustpilot's own Business Guidelines call banned** (filtering negative sentiment from the public path). Same pattern is flagged by FTC CRFA and UK DMCC Act 2025.
- Use only for small, controlled test cohorts after legal sign-off. Read `4. Documents/3 - Variant Review and Rating.docx` first.

### Reference Originals (Folder 3)

The original mailer kit, untouched. Single CTA links to a hosted choice page on `vahdamteas.com`. Fully compliant. Kept for reference and as a fallback option.

## The 7 themes (A through G)

Same seven themes inside every mailer folder. Each has a distinct visual centerpiece, so customers in different cohorts see visibly different emails — not just different words in the same layout.

| Theme | Best for | Visual centerpiece |
|---|---|---|
| **A — Chai Morning Ritual** | Default · most customers | Hero image of steaming cup + light callout |
| **B — Chai Pe Charcha** | Conversational / social cohorts | Speech bubble showing an example review |
| **C — A Few Cups In** | Loyal repeat buyers | Three stat cards (cups in / months / reviews) |
| **D — Connoisseur** | Premium SKU buyers | Tasting note card (Aroma / Body / Finish / Verdict) |
| **E — Honesty Trade** | Customers who value directness | Two-sided callout (Our side + Your side) |
| **F — Second Pour** | Non-openers (backup at T+7) | Single pill badge — shortest mailer |
| **G — One Last Thing** | Opened-no-click (backup at T+10) | Acknowledgment box before the headline |

See `4. Documents/4 - Segments and Mailer Calendar.docx` for which segment gets which theme, and when.

## Two densities — Minimal vs Lean

Every theme ships in two visual densities. The content is identical; only the visual treatment differs.

- **Minimal density** — clean, single white card on grey background. Subdued, default.
- **Lean density** — adds top/bottom black film-strip bars ("A QUICK NOTE" / "THAT'S THE WHOLE THING"), dark callout boxes, and small cream accent notes. More deliberate, more crafted, slightly heavier.

A/B-test minimal against lean within a cohort to find which visual density your audience responds to.
